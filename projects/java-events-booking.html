Java Events Booking Manager

A collaborative Java Swing application that brings campus event administration and booking workflows into one desktop interface.

JavaJava SwingGit/GitHubTeam Project

Front-end leadership

As the front-end lead, I designed and developed major user-facing workflows for a campus event-booking system. The project focused on making complex tasks such as navigating event information and booking-related actions clear and approachable in a Java Swing desktop application.

I worked within a collaborative Git/GitHub workflow, translating team requirements into interface behaviour and coordinating refinements as the application developed.

Iterative refinement

I tested user flows, debugged application behaviour, and refined the interface through iterative feedback. The project strengthened my experience with object-oriented Java development, Java Swing UI design, collaborative version control, and building a more usable front end around a multi-part application.
