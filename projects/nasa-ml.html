MACHINE LEARNING

NASA Engine Remaining Life Prediction

An end-to-end predictive-maintenance pipeline that estimates turbofan remaining useful life from NASA C-MAPSS sensor data.

PythonPandasScikit-learnXGBoostSHAPData Analysis

Predicting remaining useful life

I developed a machine-learning pipeline to predict the Remaining Useful Life (RUL) of simulated NASA turbofan engines using the C-MAPSS FD001 dataset. Using multivariate sensor and operating data, I trained and evaluated Random Forest and XGBoost regression models.

The final XGBoost model achieved a test Mean Absolute Error of 12.77 cycles, improving substantially on an initial baseline of approximately 30 cycles. The workflow covered preprocessing, exploratory data analysis, feature engineering, model training, hyperparameter tuning, and validation. I also capped RUL values to focus the models on meaningful degradation patterns closer to engine failure.

Evaluation and interpretation

I structured the work around reusable Python preprocessing functions and Jupyter notebooks, then created prediction plots, error distributions, feature-importance visualizations, and SHAP analyses to understand the model's behaviour and how individual sensor measurements influenced RUL predictions.

This project gave me hands-on experience building an end-to-end predictive-maintenance application with Python, Pandas, Scikit-Learn, XGBoost, SHAP, and data visualization.
